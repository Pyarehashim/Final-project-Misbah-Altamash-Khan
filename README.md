# Personal Web Development Portfolio

A responsive portfolio built with HTML, CSS, and JavaScript, deployed on GitHub Pages.

## Run locally
Open `index.html` in a browser.

## Deploy (GitHub Pages)
1. Push to a repo, e.g. `portfolio`.
2. Settings > Pages > Source: `main` branch, `/ (root)`.
3. Site goes live at `https://misbahaltamashkhan.github.io/portfolio/`.
